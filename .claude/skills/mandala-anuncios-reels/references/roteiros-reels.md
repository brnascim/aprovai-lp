# 9 estruturas de roteiro — corte a corte

Formato padrão de entrega:

| Tempo | Fala | Imagem | Texto na tela |
|-------|------|--------|---------------|

**Regras para todos os roteiros:**

- **0–3s decidem tudo.** Sem vinheta, sem "oi pessoal", sem "hoje eu vou falar sobre".
  Comece na frase que interessa.
- **Corte a cada 2–4 segundos** (mudança de plano, enquadramento, tela ou b-roll).
- **Legenda sempre.** A maioria assiste sem som.
- **Texto na tela ≤ 6 palavras por corte**, na área central (evite os 15% de cima e de baixo).
- **Uma ideia por vídeo.** Anúncio frio: 20–45s. Remarketing pode ir a 60–90s.
- **Fala escrita como fala:** frases curtas, contração ("tá", "pra"), repetição proposital.
- **CTA único no fim**, e mencionado uma vez só.

## 1. Problema → Solução  *(Descoberta / Conversão)*

```
0-3s    GANCHO      "Fechando a folha num domingo de novo?"        [pessoa na mesa, noite]
3-8s    AGITAÇÃO    "E o pior nem é o domingo. É refazer a mesma conferência 3 vezes."
8-15s   CAUSA       "O problema não é o sistema. É a ordem das etapas."
15-25s  SOLUÇÃO     "Quando a conferência acontece uma vez só, no lugar certo, a folha cai
                     pra 1 dia."
25-35s  PROVA       [demonstração real na tela / case autorizado]
35-45s  CTA         "Link na descrição. Toca em Saiba mais."
```

## 2. História  *(Descoberta / Relacionamento)*

```
0-3s    CENA        "Eu perdi um cliente por causa de uma planilha."   [entrar no meio da ação]
3-10s   CONTEXTO    "Nove anos fechando folha. Achei que era normal ficar até tarde."
10-20s  QUEDA       "Aí veio o mês em que eu errei o cálculo por cansaço."
20-30s  DESCOBERTA  "Foi quando eu parei e mapeei onde o tempo sumia."
30-40s  APRENDIZADO "Não era volume. Era retrabalho."
40-50s  CTA         "Se você também fecha folha no domingo, olha o link."
```
A história tem que servir a quem assiste. Se o aprendizado não é transferível, é diário
pessoal — e diário pessoal não é anúncio.

## 3. Dilema  *(Conversão)*

```
0-3s    DILEMA      "Ou você contrata mais alguém, ou continua virando a noite."
3-10s   OPÇÃO A     "Contratar: R$ 3 mil por mês e 2 meses treinando."
10-18s  OPÇÃO B     "Continuar: 12 horas suas por mês, todo mês."
18-30s  TERCEIRA    "Tem uma terceira: mudar a ordem das etapas. Custa uma tarde."
30-40s  CTA         "Explico como no link."
```

## 4. Comparação  *(Relacionamento / Conversão)*

```
0-3s    SETUP       "Planilha manual × processo em 3 colunas. Critério por critério."
3-10s   CRITÉRIO 1  "Tempo: 4 dias × 1 dia."         [split screen]
10-17s  CRITÉRIO 2  "Erro: conferência tripla × conferência única."
17-24s  CRITÉRIO 3  "Custo: zero × zero. Não precisa trocar de sistema."
24-32s  HONESTIDADE "Se seu escritório fecha 3 folhas por mês, nem precisa disso."
32-40s  CTA         "Se fecha 20, o link é pra você."
```
O bloco de honestidade aumenta conversão: quem se exclui não ia comprar mesmo, e quem fica
confia mais.

## 5. Prova / demonstração  *(Conversão / Remarketing)*

```
0-3s    ABERTURA    "Isso aqui é a planilha de um escritório real numa segunda de manhã."
3-12s   CONTEXTO    "Olha o horário. 7h40. Três arquivos abertos."   [gravação de tela real]
12-25s  DEMO        [mostrar o processo funcionando — sem cortes que "sumam" com etapas]
25-35s  RESULTADO   "Mesmo sistema. Fechou 11h20."
35-45s  CTA         "O processo inteiro tá no link."
```
Só com material real e autorizado. Demonstração editada para esconder etapa é prova falsa.

## 6. Explicação / mecanismo  *(Relacionamento)*

```
0-3s    PROMESSA    "Em 30 segundos: por que a folha demora 4 dias."
3-12s   PARTE 1     "Etapa 1: entrada de dados. Aqui não é o problema."
12-22s  PARTE 2     "Etapa 2: conferência. É aqui. Acontece 3 vezes."   [diagrama na tela]
22-32s  PARTE 3     "Etapa 3: fechamento. Herdando o erro das duas anteriores."
32-40s  SÍNTESE     "Uma conferência, no lugar certo. É o método das 3 colunas."
40-48s  CTA         "Link."
```
Melhor formato para sustentar ticket alto: quem entende o mecanismo aceita pagar mais.

## 7. Apelo emocional  *(Descoberta)*

```
0-3s    IMAGEM+FALA "Meu filho já sabe que domingo à noite eu não tô disponível."
3-12s   SENTIMENTO  "Não é sobre trabalhar muito. É sobre trabalhar à toa."
12-22s  VIRADA      "Quando eu vi que 12 horas por mês eram retrabalho, doeu."
22-32s  RESOLUÇÃO   "Hoje eu fecho no dia 3 e desligo o computador."
32-40s  CTA         "Se você quer isso, o link tá aqui."
```
Alcance alto, qualificação baixa. Use para topo, não para conversão direta.

## 8. Exagero / humor  *(Descoberta)*

```
0-3s    CENA        [pessoa cercada de papel, café frio]  "Dia 5. Ele chega sempre."
3-10s   EXAGERO     "Já pensei em pedir feriado municipal de fechamento de folha."
10-20s  VIRADA      "Aí eu descobri que o problema não era o dia 5."
20-30s  REAL        "Era a conferência acontecendo 3 vezes."
30-38s  CTA         "Link."
```
Humor que ri **com** o público (da situação), nunca **do** público. Rir do cliente destrói
autoridade.

## 9. Impacto visual  *(Descoberta)*

```
0-2s    IMPACTO     [ação visual forte, sem fala: pilha de papel caindo / timer correndo]
2-6s    FALA        "4 dias. Todo mês. Pra fechar uma folha."
6-16s   CONTEXTO    "Nenhum escritório precisa disso."
16-28s  MECANISMO   "Muda a ordem das etapas e cai pra 1."
28-36s  CTA         "Link."
```
Melhor retenção nos 3s, menor profundidade. Ótimo para testar se o público responde a
visual antes de argumento.

## Biblioteca de ganchos de 3 segundos (vídeo)

| Tipo | Exemplo | Funciona porque |
|------|---------|-----------------|
| Frase literal | "'Eu fecho a folha no domingo.'" | Reconhecimento imediato |
| Pergunta situacional | "Fechando a folha agora?" | Filtra e chama |
| Número | "12 horas por mês. Só reconferindo." | Concreto |
| Contradição | "Trocar de sistema não vai resolver." | Quebra expectativa |
| Ação em curso | [já mexendo na planilha] "Olha o que acontece aqui." | Sensação de flagrante |
| Erro confessado | "Eu errei uma folha inteira por cansaço." | Vulnerabilidade gera atenção |
| Exclusão | "Se você fecha 3 folhas por mês, pode pular esse vídeo." | Paradoxo da exclusão |
| Objeto/gesto | [mostra a pilha de papel] "Isso aqui é um mês." | Visual antes de verbal |

**Nunca comece com:** "Oi, tudo bem?", "Eu sou o [nome] e...", "Hoje eu vou falar sobre",
vinheta, logo animada, "seguinte, galera".

## Hook stacking (3 criativos pelo preço de 1)

Grave **o corpo do vídeo uma vez** e **três aberturas diferentes** (famílias diferentes de
gancho). Na edição, monte três vídeos. É a forma mais barata de multiplicar criativo — e
isola exatamente a variável que mais importa.

```
Corpo (gravado 1×)  +  Gancho A  →  Criativo 1
                    +  Gancho B  →  Criativo 2
                    +  Gancho C  →  Criativo 3
```

## Variantes sem aparecer em vídeo

Para quem não grava o próprio rosto — todas rodam bem:

| Variante | Como |
|----------|------|
| Gravação de tela | Mostrar o processo/ferramenta com voz por cima |
| Mãos + mesa | Plano zenital de papel, caderno, produto |
| Texto animado | Frases entrando no ritmo de uma trilha, com b-roll |
| Voz + b-roll | Narração sobre imagens de banco ou cenas do ambiente |
| Entrevista/áudio de cliente | Com autorização escrita |
| Ilustração/diagrama | Ótimo para "Explicação" e "Comparação" |

## Checklist do roteiro

- [ ] O gancho está nos primeiros 3 segundos e não precisa de contexto anterior
- [ ] Um corte a cada 2–4s
- [ ] Uma ideia só
- [ ] Legenda prevista
- [ ] Texto na tela ≤ 6 palavras por corte, fora das faixas de interface
- [ ] CTA único, dito uma vez
- [ ] Nenhuma prova inventada
- [ ] Sem promessa de renda, atributo pessoal ou antes/depois corporal
- [ ] O usuário consegue gravar isso com o que tem
